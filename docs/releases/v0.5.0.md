# FactoryGuard v0.5.0: held-out evaluation, calibrated intervals, measurement review

Builds on the v0.4.0 investigation-alert and assistant prototype. This release closes the
open scientific items rather than adding features.

## What is new

- **Sealed reserve evaluated once.** After owner authorization and a recorded
  pre-execution review, the frozen method (exponential smoothing, alpha 0.5) was run once on
  B03: **14.2% lower MAE than persistence** (ratio 0.857 on A, 0.859 on C, 611 pairs), in
  line with the 12.83% development estimate. Where operating conditions did not change
  between bursts (31 pairs) there was no gain. [Result](../results/b03-holdout/README.md).
- **Independent reproduction.** Features for B01/B02/B04 were re-extracted from freshly
  downloaded raw archives and matched the published hashes bit for bit; the 32-candidate
  selection campaign was rerun and reproduced every published metric and the same
  selection. [Review](../results/b03-holdout/review.md).
- **Calibrated prediction intervals.** Causal conformal calibrators were compared on B01/B02
  under a pre-declared rule; the selected adaptive, scale-relative calibrator was frozen
  before B03 was opened and then covered **89.5% / 89.4%** of B03 errors at a 90% target,
  where fixed bands covered about half of late-run errors.
  [Method and results](../uncertainty_calibration.md).
- **Measurement validity.** B04's logged shaft speed (half the commanded value) was tested
  against the rotation frequency in the raw vibration spectrum: the shaft ran at the
  commanded speed, and the log column is a scaling artefact. The dynamic-load column stays
  open. [Review](../results/measurement-validity/README.md).
- **Alert validation, closed honestly.** The dataset has no dated fault events or verified
  normal intervals, so recall, false-alert rate and detection delay are not measurable and
  are not claimed. An acceptance protocol with thresholds is fixed for future labelled data.
  [Status](../alert_validation.md).
- **MIT licence** for the software; dashboard text updated for the held-out result.

## Verification

- Python suite: 195 tests passing locally (183 before this release, plus interval
  calibration and speed-audit tests).
- Remote CI status for the release commit is recorded on the GitHub release page.

## Platform scope (unchanged from v0.4.0)

Linux assistant and Windows/Linux core checks are required. The Windows assistant is
explicitly excluded from this prototype: its job remains visible and advisory because of an
unresolved native-import delay documented in the assistant guide.

## Not claimed

Fault detection, damage onset, health classification, remaining useful life, population
generalisation from one held-out bearing, or live-equipment operation.
