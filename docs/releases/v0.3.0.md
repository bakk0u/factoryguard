## Supported capabilities

- Three-view dashboard: overview, experiment exploration, methods/evidence.
- Real precomputed RMS observations, saved forecasts/persistence and settled errors,
  temperature above ambient, measured/commanded context, acquisition gaps and warnings.
- Fixed development-reference support and descriptive sudden/sustained evidence;
  optional sequential replay, keyboard history inspection and selected periods.
- Browser-local snapshot/experiment-isolated notes, legacy-note export,
  blocked-storage fallback and downloadable reports with explicit provenance.
- Complete standalone CI artifact and public static presentation; optional local
  Python/SQLite replay application, streaming ingestion and reproducible saved results.

## Data and model comparison

B01/B02 are development runs; B04 is diagnostic with unresolved measured speed/load
scaling, retained uncorrected. B03 remains sealed. A/C are channels on each bearing,
not separate machines. The site includes 2,607 recorded observations/predictions/
errors and 432 saved comparison rows, without raw waveforms or private notes.

Smoothing was selected from the bounded development procedure: **12.83%
equal-run/channel MAE improvement** versus persistence. This is development-selection
improvement, not held-out accuracy or fault-detection performance. The overview
compares best-performing evaluated variants within families; full tables retain
all variants and unfavorable results. Historical out-of-run settings (.2 for B01,
.5 for B02, .2 diagnostic B04) are distinct from the final alpha .5 configuration.

## Known limitations

Only two independent development bearings, repeated selection use and sparse or
unsupported operating conditions limit inference. Ordinal CSV/MAT alignment,
measurement timestamp meaning/timezone, sensor-range/response and termination
criteria remain qualified. B04 is not a clean third test. Next-observed burst is
not a fixed horizon. Development reference distributions are not healthy/safe ranges.
No fault detection, health classification, damage onset, failure probability or RUL
has been validated. Improved forecasting does not establish improved fault detection.

Original result-producing commit and generation time are unknown and explicitly
null; the website-build commit and snapshot hashes are separately recorded. Browser
storage may be blocked; export notes before closing if only tab storage is available.
The static site has no live equipment, server persistence or enterprise-service claims.
